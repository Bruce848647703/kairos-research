# 05 · 真实组合风险：VaR/ES、成分可加性、系统性占比、肥尾、PSR/DSR

> 问题：一个真实的 38 只 A 股逆波动组合，风险到底多大？VaR 的几种口径差多少？成分风险是否可加？分散化为何失效？尾部有多肥？这个夏普有多大概率不是运气？
> 数据：`kairos-risk/real_risk`（inverse_vol 组合、38 标的、1921 个收益期、2018-10-30 ~ 2026-09-24、组合市值 1 亿元、主口径 95%/尾部 99%/99.9%）。

## 背景 / 问题

[01](01-anomaly-map.md) 已指出这篮子蓝筹 94.58% 的方差来自单一市场因子。本篇从风险侧量化：组合的 VaR/ES、成分风险可加性、分散化失效的程度、尾部肥厚（EVT）、以及用 PSR/DSR 给回测夏普「打折」。

## 数据与方法

- 组合：inverse_vol 静态权重（样本内一次性确定，不含调仓与成本），市值 10,000.0 万元；权重最大 6.60%（sh601398）、最小 1.46%、权重 HHI 0.0312、权重有效资产数 32.08 (来源: kairos-risk/research/real_risk/risk_metrics.json `portfolio`)。
- 数据清洗：前复权可能为负 → 裁剪到公共正价窗口（丢弃 23404 条早期价）→ 涨跌停硬约束下界修复 → 残余越界 clip；清洗后单日最大绝对收益 19.75%（落在物理约束内） (来源: kairos-risk/research/real_risk/risk_metrics.json `data`；详见 [09](09-data-methodology.md)）。
- 组合层面：年化收益 10.87%（几何）、年化波动 14.88%、夏普 0.730、Sortino 1.134、偏度 -0.0707、**超额峰度 4.4249**、最好/最差单日 +5.79%/-6.03%、胜率 50.70% (来源: kairos-risk/research/real_risk/risk_metrics.json `measures`)。

## 结果

### 1. VaR / ES 多口径对比（每期损失率，正数口径）

| 置信度 | 历史 VaR | 参数 VaR(正态) | 参数 VaR(学生 t) | 修正 VaR(CF) | 历史 ES | ES(正态) | ES(学生 t) |
|---|---|---|---|---|---|---|---|
| 95% | 1.34% | 1.50% | 1.43% | 1.43% | 2.08% | 1.89% | 2.04% |
| 99% | 2.52% | 2.13% | 2.38% | **3.15%** | 3.46% | 2.45% | 3.13% |

(来源: kairos-risk/research/real_risk/risk_metrics.json `measures.var`/`es`)

- 95% 档四种 VaR 差异不大（1.34%~1.50%），中位尾部主要由波动驱动；到 99% 档，**学生 t（2.38%）与 Cornish-Fisher 修正（3.15%）明显高于正态法（2.13%）**——这正是超额峰度 4.42 带来的肥尾效应。
- ES 恒 ≥ 同置信度 VaR（99%：3.46% vs 2.52%），满足一致性公理。
- 换算金额（市值 1 亿）：95% 单日历史 VaR ≈ **134.3 万元**、ES ≈ 208.4 万元；99% VaR ≈ 251.6 万元、ES ≈ 346.5 万元；按 √T 年化，99% 历史 VaR ≈ 39.94% (来源: kairos-risk/research/real_risk/REPORT.md)。

### 2. 成分风险可加性（欧拉分配，达浮点精度）

| 指标 | 数值 | 含义 |
|---|---|---|
| 组合每期波动 σp | 0.009371（年化 14.88%） | — |
| Σ 成分风险 CRC | 0.009371 | **绝对误差 1.735e-18**（精确可加） |
| Σ 成分 ES / 组合 ES | 0.020843 / 0.020843 | 误差 0.000e+00 |
| Σ 成分 VaR / 组合 VaR | 0.013431 / 0.013431 | 误差 3.469e-18 |
| 分散化比率 DR | **1.7718** | 加权个体波动 0.016604 / σp |
| DR 零相关上界 √n | 6.1644 | 实际只达到其 **28.7%** |
| 风险有效资产数 | **36.63** | 名义 38 只；风险 HHI 0.0273（完全均等 1/n=0.0263） |

(来源: kairos-risk/research/real_risk/risk_metrics.json `decomposition`)

- 风险贡献最大的是 sh601318（3.49%）、sz000858（3.47%）、sh600030（3.28%），前三合计仅 10.2%——**逆波动权重确实把风险贡献拉平了**（风险有效 36.6/名义 38）。

### 3. 系统性占比：分散化被相关性吃掉

- 以同样本 38 只等权组合作市场代理（年化 13.20%/17.27%），组合市场暴露 **β_p = 0.8503**，**系统性（因子）方差占比 94.58%**、特质仅 5.42%；因子/特质/总方差可加性误差 0.000e+00 (来源: kairos-risk/research/real_risk/risk_metrics.json `factor`)。
- 个股单因子 R² 中位 0.316、beta 中位 1.036（最小 0.179 sh601398、最大 1.868 sz300059）；模型隐含波动/样本波动 = 1.0147 (来源: kairos-risk/research/real_risk/risk_metrics.json)。

> **核心矛盾**：DR 只有 1.772（零相关上界 √n=6.16 的 29%），约 **71% 的分散化收益被 A 股高相关性吃掉**；风险贡献分散了，但**风险本身没分散**——这样的多头分散组合本质是一个 **β≈0.85 的市场敞口** (来源: kairos-risk/research/real_risk/REPORT.md)。

### 4. 肥尾（EVT：Hill + GPD 两条独立路径互证）

| 指标 | 数值 |
|---|---|
| Hill 尾指数 ξ̂ | **0.4486** ± 0.0324（k=192，超出 192/1921 观测） |
| 帕累托尾指数 α=1/ξ | 2.229 |
| ξ̂ 在 k∈[20,480] 范围 | 0.288 ~ 0.716（中位 0.491，全程正号） |
| GPD ξ / scale（scipy_mle） | 0.2139 / 0.00594 |
| GPD 阈值 u / 超出数 Nu / 超出概率 ζ | 0.01343 / 96 / 0.0500 |
| 尾部比率 ES/VaR(95%) | 1.5518（正态约 1.25） |

(来源: kairos-risk/research/real_risk/risk_metrics.json `tail`)

POT/GPD 外推 vs 经验口径：

| 置信度 | POT VaR | POT ES | 历史 VaR | 正态 VaR | 学生 t VaR | POT VaR 金额 |
|---|---|---|---|---|---|---|
| 99.0% | 2.48% | 3.55% | 2.52% | 2.13% | 2.38% | 248.3 万元 |
| 99.9% | **4.98%** | 6.72% | 4.71% | 2.85% | 4.11% | **497.5 万元** |

(来源: kairos-risk/research/real_risk/risk_metrics.json `tail.pot`)

- Hill ξ=0.449>0 且全网格正号，GPD ξ=0.214 同号同量级——**真实 A 股组合收益确为肥尾**。外推到 99.9%（1921 期里平均只有 1.9 天，历史法几乎无观测）：POT VaR 4.98%（≈497.5 万元）是正态法（2.85%）的 **1.7 倍**。**越往尾部走，正态法越低估风险**。

### 5. 回撤与压力（补充视角）

- 回撤：**MDD 23.95%**、当前回撤 11.84%、最长水下 **1097 个交易日（≈4.4 年）**、水下时间占比 **94.12%**、Calmar 0.4537、53 个回撤区间；最深区间 2021-02-10 峰 → 2022-10-31 谷（413 日）→ 2025-08-25 收复（共 1098 日水下） (来源: kairos-risk/research/real_risk/risk_metrics.json `drawdown`)。
- 压力：市场 -20%（+波动×1.8）情景亏 **1,700.5 万元**（-17.01%），冲击后 95% 单日 VaR 升至 19.78%；历史最差单日重放（2020-02-03）亏 **602.8 万元**（= 99% 历史 VaR 的 **2.40 倍**）；最惨 21 日窗口亏 1,199.5 万元（-12.00%）；亏 10% 市值需市场跌 11.8%（反向压力 λ=0.59） (来源: kairos-risk/research/real_risk/risk_metrics.json `stress`)。

### 6. PSR / DSR：给回测夏普打折

| 试验次数 N | DSR | PSR | 门槛 SR₀ | 缩水幅度 |
|---|---|---|---|---|
| 1（不做多重检验修正） | 0.9827 | 0.9827 | 0.0000 | 0.0000 |
| 38（在 38 只里挑这一组合） | 0.4804 | 0.9827 | 0.0495 | 0.5023 |
| 100（更大范围搜索） | **0.3411** | 0.9827 | 0.0578 | 0.6415 |

(来源: kairos-risk/research/real_risk/risk_metrics.json `backtest.dsr`)

- 年化夏普 0.7679、样本 1921 期，**PSR=0.9827**（不做多重检验修正时跑赢零夏普概率很高）；最小跟踪长度 1158 期（实际 1921 期已够）；胜率 50.70%（Wilson 95% CI [48.47%, 52.93%]）；21/252 日内重演历史最差单日的概率 1.09%/12.30% (来源: kairos-risk/research/real_risk/risk_metrics.json `backtest`)。
- **但一旦承认它是在 38 只里挑出来的（N=38），DSR 降到 0.480；N=100 进一步降到 0.341**（门槛 SR₀ 从 0 抬到 0.0578）。这就是**回测过拟合的代价**：同样的历史夏普，试验次数越多、可信度越低。本组合是逆波动权重（几乎无参数搜索），故 N=1 与 N=标的数两档更接近其真实显著性。

## 解读

- 25 项一致性校验全部通过（欧拉可加、尾部可加、因子+特质=总、ES≥VaR、分位单调、学生 t≥正态、DR≥1、DSR≤PSR 且随 N 单调不增、Hill ξ>0、JSON 严格合法等），关键误差量级 1e-18 (来源: kairos-risk/research/real_risk/risk_metrics.json `checks`)。数字内部自洽，可信。
- 风险画像三句话：**水平适中**（年化波动 14.88%、95% 日 VaR 1.34%）、**分散失效**（DR 1.77、系统性 94.58%、β 0.85）、**尾部肥+回撤长**（Hill 0.449、MDD 23.95%、水下 94.12%、最长 4.4 年）。
- PSR 0.983 与 DSR 0.341 的巨大落差，是整套研究里关于「回测可信度」最重要的一课。

## 局限 / 后续

- 静态权重、不含调仓与成本；市场因子由同一篮子等权构成（代理市场，非独立基准）。
- 前复权下界修复是保守估计，高分红标的早期（2019-2021）收益仍可能被小幅高估、波动/VaR 偏保守（偏大） (来源: kairos-risk/research/real_risk/REPORT.md)。
- 后续：加入调仓/成本、用独立宽基指数的市场因子、对尾部做含杠杆的目标波动管理。
